What each record contains

FieldTypeMeaning
idstringStable slug, also the calculator's ?model= parameter (e.g. gpt-5.5).

tokenizerstringtiktoken:o200k_base / tiktoken:cl100k_base = exact official BPE; estimate = calibrated character ratio.
estimateobjectOnly for estimated models: charsPerToken for Latin text and tokensPerCJKChar.
contextWindowstringMax input context as published (e.g. 1M, 200K).
priceInputPer1MnumberUSD per 1M input tokens.
priceOutputPer1Mnumber|nullUSD per 1M output tokens; null for output-free models such as embeddings.
notestring?21 records carry caveats — reasoning, intro pricing, free, tiered, open-weight, launch dates.
_metaobjectLicense, citation string, lastVerified date, unit, and counting-method notes.

How the numbers are gathered

Each price is the provider's public list price in USD, read from the vendor's own pricing page and cross-checked against a second source where one exists. The verification date in _meta.lastVerified applies to the whole file. Not included: batch, cached-input, fine-tuned, provisioned-throughput or contract rates, and image/video/audio billing that some providers express per second or per image instead of per token. Prices move — treat this as a dated snapshot, not a live feed.

Pricing data FAQ

Is the AI model pricing JSON free to use?

Yes. It is licensed CC BY 4.0: use it commercially, modify it, redistribute it. The only requirement is attribution — a link to tokenestimate.com or the citation line TokenCalc, "AI Model Token Pricing Data", tokenestimate.com, 2026.

How many models and providers does the dataset cover?

81 models across 26 provider groups as of 2026-10-02, spanning OpenAI, Anthropic, Google, Meta, xAI, Mistral, Amazon and the major Chinese labs (DeepSeek, Qwen, GLM, Kimi, Doubao, ERNIE, Hunyuan, Spark, MiniMax, 01.AI, StepFun, SenseTime, Baichuan, Kunlun, Xiaomi, Huawei).

Are the prices exact?

They are the providers' published list prices, verified 2026-10-02, in USD per 1M tokens. Discounted tiers — batch, cached input, long-context surcharges, contract pricing — are not modelled, so check the provider page before you publish a number or send a bill.

How often is the dataset updated?

Whenever model pricing changes; the file carries its own _meta.lastVerified date, so you can decide for yourself whether a value is current instead of trusting a changelog.

Why do some records say "estimate" in the tokenizer field?

OpenAI publishes tiktoken, so 18 of the records are counted with the official BPE tokenizer. Other vendors do not publish their tokenizer, so token counts for them are calibrated character-ratio estimates (about 4 characters per English token), accurate to roughly 5–10%. The tokenizer field tells you which case a record is in.

Can I hotlink the JSON from my app?

Yes, and it is served with permissive CORS. The URL is stable, and because it is a plain static file it will keep working without a key, quota or plan.

What does a null priceOutputPer1M mean?

The model has no output price because it produces embeddings rather than generated text — e.g. text-embedding-3-small at $0.02 per 1M input tokens. Treat null as "not applicable", not as "free".
