How accurate is the GPT-4o mini count?

The count on this page is exact. GPT-4o mini is billed by OpenAI using the o200k_base Byte-Pair-Encoding tokenizer, and TokenCalc runs that same tokenizer in your browser — the count you see is the count you are charged. There is no rounding and no estimate.

## What fits in the GPT-4o mini context window GPT-4o mini accepts **128K tokens**. At roughly 1.3 tokens per English word that is about **98,461 words**, or roughly **512,000 characters** of prose. Code and CJK text consume the budget faster: a source file or a Chinese document of the same visible length can run 30–60% more tokens, so leave headroom rather than budgeting to the exact ceiling.

GPT-4o mini token FAQs

How many tokens is a word in GPT-4o mini?

About 1.3 tokens per English word for GPT-4o mini — roughly 4.0 characters per token. Code and CJK text tokenize denser, so a 128K tokens window holds fewer words than a prose estimate suggests.

What does GPT-4o mini cost per 1M tokens?

GPT-4o mini is listed at $0.15 per 1M input tokens and $0.6 per 1M output tokens as of 2 October 2026.

What is the GPT-4o mini context window?

GPT-4o mini accepts up to 128K tokens of input.

Is the GPT-4o mini token count on this page exact?

Yes. TokenCalc runs the official o200k_base tokenizer, the same one OpenAI bills with.

Does this GPT-4o mini calculator upload my text?

No. Tokenization runs entirely in your browser over JavaScript. Your text is never sent to any server, which is why the tool works with client code, unreleased prompts and internal data.
