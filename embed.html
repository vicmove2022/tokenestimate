The one-line embed

Drop this anywhere in the <body> of the page where you want the calculator. The script creates the iframe and sizes it for you.

<script src="https://tokenestimate.com/js/embed.js" data-model="gpt-5.5" data-height="640"></script>

Options

data-modelgpt-4oModel preselected when the widget loads. Use any id from the deep-link table below.

data-creditonSet data-credit="off" to drop the small "Token calculator by TokenCalc" line under the widget. Linking back keeps it free.

Iframe version (no script allowed)

Some CMSs, Shopify themes and docs platforms strip third-party <script> tags. Use the raw iframe instead — it is the same widget:

<iframe src="https://tokenestimate.com/?embed=1&model=gpt-5.5"
        title="AI Token Calculator" loading="lazy"
        style="width:100%;max-width:1080px;height:640px;border:1px solid #dfe6f1;border-radius:16px"></iframe>

Troubleshooting

  • The widget is blank — your host may block iframes. Check for X-Frame-Options or a CSP frame-src rule; our site sends neither, so the restriction is on your side.
  • It is cut off — raise data-height. The pricing table under the calculator needs the extra room.
  • Counts look wrong — confirm the data-model id actually exists in the table above; an unknown id silently falls back to GPT-4o.
  • First count is slow — the OpenAI dictionary downloads once (~2.3 MB) and is then cached in that visitor's browser.

Embed FAQ

Is the token calculator widget free to embed?

Yes. One line of HTML, free on any site including commercial ones. No API key, no account, no rate limits. The only condition is keeping the link back to tokenestimate.com.

Does the embed send visitor text to your servers?

No. Tokenization runs in the visitor's browser, and the calculator page has no backend to send anything to. Nothing is uploaded, logged or stored server-side.

Can I embed it in WordPress, Notion, Shopify or a docs site?

Use the iframe version if your platform strips third-party scripts. WordPress (custom HTML block), Shopify (page metafields or a section), Ghost and most static-site generators accept the iframe directly. Notion only accepts embeds of pages it can preview, so link to the tool instead.

How do I change which model loads first?

Set data-model="model-id" on the script tag, or ?model=model-id in the iframe URL. ids like gpt-5.5, claude-opus-5-5, gemini-3.1-pro and deepseek-v4-pro are listed above.

Can I remove the "TokenCalc" credit line?

data-credit="off" hides the text under the widget, but the embed stays free on the condition that the page links to tokenestimate.com — keep the in-widget link or add your own.

Are the token counts exact?

OpenAI models use official tiktoken, so counts match what the API bills. Other providers use a calibrated estimate accurate to roughly 5–10%, marked with an "estimate" badge inside the widget.

Does embedding slow down my page?

Barely. The iframe is loading="lazy", so nothing loads until a visitor scrolls it into view, and the tokenizer only downloads when someone actually counts text.
